# CakeHub AI Bot 3.4 Clean

Чистая версия без GitHub Models. Все AI-функции работают через AITunnel.

## Возможности
- постоянная нижняя клавиатура;
- текстовый AI-чат;
- выбор AI-агента;
- генерация изображений;
- анализ фотографий;
- SQLite-история;
- работа в группах по имени, упоминанию или `/bot_on`;
- без админ-панели.

## Запуск Windows
1. Распакуйте архив.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `TELEGRAM_BOT_TOKEN` и `AITUNNEL_API_KEY`.
4. При необходимости измените модели на доступные в вашем тарифе AITunnel.
5. Запустите `run_windows.bat`.

## Нижняя панель
После `/start` доступны кнопки:
- 💬 AI-чат
- 🎨 Создать картинку
- 🔍 Анализ фото
- 🤖 Выбрать AI-агента
- 🧹 Очистить историю
- ℹ️ Помощь

## Группы
В BotFather отключите Privacy Mode: `/setprivacy` → бот → Disable.
Затем вызовите бота по `@username`, слову «КейкХаб» или командой `/bot_on`.

## Важно
Названия моделей зависят от доступа в AITunnel. При ошибке `model_not_found` замените `AITUNNEL_CHAT_MODEL`, `AITUNNEL_VISION_MODEL` или `AITUNNEL_IMAGE_MODEL` в `.env`.
