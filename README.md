# CakeHub AI Bot 3.3 Final

Telegram-бот для кондитеров: чат и анализ фото через GitHub Models, генерация/редактирование изображений через AITunnel, SQLite, очередь задач, галерея и админ-статистика.

## Возможности
- AI-чат с историей 20 сообщений и автоматическим fallback между моделями.
- Анализ фотографий.
- Генерация изображений `/image`.
- Редактирование присланных изображений обычным текстом.
- Кнопки «Улучшить», «Удалить фон», «Галерея».
- Асинхронная очередь и несколько workers.
- Команда администратора `/stats`.
- Docker, Railway и запуск Windows.

## Запуск Windows
1. Установите Python 3.12.
2. Скопируйте `.env.example` в `.env`.
3. Заполните `TELEGRAM_BOT_TOKEN`, `GITHUB_TOKEN`, `AITUNNEL_API_KEY`, `ADMIN_IDS`.
4. Запустите `run_windows.bat`.

## Railway
Создайте проект из GitHub, добавьте переменные из `.env.example` и подключите Volume к `/app/data` для постоянной SQLite и галереи.

## Важно о моделях
Названия доступных моделей могут меняться. Укажите реальные ID из каталога GitHub Models в `GITHUB_CHAT_MODELS` и `GITHUB_VISION_MODELS`. Бот последовательно пробует модели из списка.

Для AITunnel укажите модель изображения, доступную вашему тарифу. По умолчанию стоит `gpt-image-1-mini`; при необходимости замените на `gpt-image-2`.
