# CakeHub AI Bot 3.3 Final — без администратора

Telegram-бот для кондитеров: чат и анализ фото через GitHub Models, генерация и редактирование изображений через AITunnel, SQLite, очередь задач и личная галерея.

## Возможности
- AI-чат с историей 20 сообщений и автоматическим переключением между моделями.
- Анализ фотографий.
- Генерация изображений командой `/image`.
- Редактирование присланных изображений обычным текстом.
- Кнопки «Улучшить», «Удалить фон» и «Галерея».
- Асинхронная очередь и несколько обработчиков задач.
- SQLite для истории и галереи.
- Docker, Railway и запуск в Windows.
- Администратор и административные команды отсутствуют.

## Запуск в Windows
1. Установите Python 3.12.
2. Скопируйте `.env.example` и переименуйте копию в `.env`.
3. Заполните `TELEGRAM_BOT_TOKEN`, `GITHUB_TOKEN` и `AITUNNEL_API_KEY`.
4. Запустите `run_windows.bat`.

## Railway
Создайте проект из GitHub, добавьте переменные из `.env.example` и подключите Volume к `/app/data`, чтобы SQLite и галерея сохранялись после перезапусков.

## Важно о моделях
Названия доступных моделей могут меняться. Укажите реальные ID моделей, доступных вашему GitHub-токену, в `GITHUB_CHAT_MODELS` и `GITHUB_VISION_MODELS`. Бот последовательно пробует модели из списка.

Для AITunnel укажите модель изображения, доступную вашему тарифу. По умолчанию используется `gpt-image-1-mini`.
